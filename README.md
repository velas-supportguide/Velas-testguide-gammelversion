# Velas' videoguide – gammel version (29. oktober 2026 kl. 11.00)

Dette er en uændret kopi af videoguiden, som den så ud den 29. oktober 2026 kl. 11.00,
da søgefunktionen blev testet første gang med 20 spørgsmål.

Kopien er taget fra den gemte udgave `a5936ba` ("Tydeligere grøn markering af stærke match
i søgeresultaterne") i det oprindelige repository. Den bruges til at sammenligne den første
udgave med den nuværende side.

For at sammenligningen kun handler om søgefunktionen, er to ting fjernet fra kopien:

- knappen "Sådan virker siden" og rundvisningen i tre trin
- knappen "Har du brug for hjælp?" og kontaktvinduet

Søgningen, søgeordene og mærkerne Stærkt match, Godt match og Muligt match er uændrede.

Den nuværende side ligger i repositoriet `velas-supportguide/Velas-videoguide`.
